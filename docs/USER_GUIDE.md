# Руководство пользователя

Это руководство описывает установку, настройку и использование Telegram-бота
для генерации дипломов и подарочных сертификатов в PDF.

## Требования

- Windows и PowerShell (инструкции ниже подготовлены для Windows).
- Python 3.10 или новее.
- Токен бота, созданного через BotFather.
- Системные компоненты WeasyPrint, если их требует ваша версия Windows/Python.
  При ошибках установки следуйте актуальной инструкции установки WeasyPrint.

## Установка

Откройте PowerShell в папке проекта `VPa06` и выполните:

```powershell
python -m venv .\venv
.\venv\Scripts\Activate.ps1
python -m pip install -r .\requirements.txt
```

Если PowerShell запрещает запуск скрипта активации, используйте Python
виртуального окружения напрямую:

```powershell
.\venv\Scripts\python.exe -m pip install -r .\requirements.txt
```

## Настройка `.env`

Скопируйте пример и откройте файл для редактирования:

```powershell
Copy-Item .\.env.example .\.env
notepad .\.env
```

Укажите настройки:

```dotenv
BOT_TOKEN=токен_от_BotFather
ALLOWED_USER_IDS=123456789
PDF_RETENTION_DAYS=30
```

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | Секретный токен Telegram-бота. Обязателен. |
| `ALLOWED_USER_IDS` | Числовые Telegram ID операторов, которым разрешён выпуск. Несколько ID разделяются запятыми. Если значение пустое, документы выпускать нельзя. |
| `PDF_RETENTION_DAYS` | Срок хранения PDF в днях. Положительное целое число; по умолчанию `30`. |

### Получение Telegram ID

1. Оставьте `ALLOWED_USER_IDS` пустым, если пока не знаете ID.
2. Запустите бота и отправьте ему `/myid`.
3. Скопируйте числовой ID из ответа.
4. Остановите бота клавишами **Ctrl+C**.
5. Укажите ID, например `ALLOWED_USER_IDS=123456789`, сохраните `.env` и
   запустите бота снова.

Для нескольких операторов используйте список через запятую:

```dotenv
ALLOWED_USER_IDS=123456789,987654321
```

`.env` содержит секретный токен. Не публикуйте его, не добавляйте в Git и не
отправляйте посторонним. Если токен оказался опубликован, отзовите его через
BotFather и замените новым. `.env.example` предназначен для публикации и не
должен содержать реальный токен или приватные Telegram ID.

## Запуск и остановка

Из папки проекта запустите:

```powershell
python .\bot_generator.py
```

Остановить бота можно сочетанием **Ctrl+C** в том же окне терминала. После
изменения `.env` бот необходимо перезапустить.

## Команды

| Команда | Назначение |
|---|---|
| `/start` | Показать приветствие и доступные команды. |
| `/myid` | Узнать числовой Telegram ID отправителя. |
| `/diploma` | Начать выпуск диплома или списка дипломов. |
| `/gift` | Начать выпуск подарочного сертификата или списка сертификатов. |
| `/resend ID` | Повторно отправить сохранённый PDF по ID документа. |

Выпуск и повторная отправка доступны только ID из `ALLOWED_USER_IDS` и только
в личном чате с ботом. Групповые чаты для этих операций запрещены.

## Пакетный выпуск документов

После `/diploma` или `/gift` отправьте все записи одним сообщением, по одной
записи на каждой строке:

```text
Анна Иванова : Python : diploma-001
Борис Петров : Веб-разработка : diploma-002
Вера Сидорова : Дизайн : diploma-003
```

Структура каждой строки:

```text
Имя : Название курса или услуги : ID документа
```

Бот проверит весь список, создаст отдельный PDF для каждой записи и отправит
файлы по очереди. Если формат хотя бы одной строки неверный, исправьте список
и отправьте пакет заново. Для отмены вместо списка отправьте команду, которая
начинается с `/`.

### Ограничения полей

- От 1 до 10 непустых записей в одном сообщении.
- Имя обязательно, не более 120 символов.
- Название обязательно, не более 200 символов.
- ID обязателен, от 1 до 64 букв, цифр, подчёркиваний или дефисов.
- ID должны быть уникальны в текущем пакете и в журнале всех ранее выданных
  документов. Повторное использование ID запрещено, даже после удаления PDF.
- Двоеточие — разделитель полей, поэтому его нельзя включать в имя или название.

## Лимит выпуска

Оператор может выпустить не более **10 PDF за скользящее окно в 10 минут**.
Считаются документы, а не сообщения: пакет из пяти записей занимает пять
позиций лимита. Проверка выполняется при записи документов в журнал.

Повторная отправка через `/resend ID` не создаёт новый документ и не расходует
лимит выпуска.

## Повторная отправка

В личном чате с разрешённого аккаунта отправьте:

```text
/resend diploma-001
```

Бот найдёт PDF по ID в журнале и отправит его, если файл ещё существует и не
истёк срок хранения. Повторная отправка не продлевает срок хранения.

## Хранение документов

Готовые PDF сохраняются в `output/` под именами вида:

```text
document_<ID>_<chat_id>_<message_id>.pdf
```

В той же папке хранится база `issued_documents.sqlite3` с журналом ID, временем
выпуска, именем PDF и Telegram ID оператора. Папка `output/` создаётся
автоматически и исключена из Git.

PDF старше `PDF_RETENTION_DAYS` удаляются при старте бота и перед командами
выпуска или повторной отправки. Записи ID в SQLite остаются, поэтому
использованные номера нельзя выдать повторно. После удаления PDF команда
`/resend` не сможет восстановить документ; для долгосрочного хранения настройте
защищённое резервное копирование PDF и базы.

## Защита и ограничения

- Авторизация выполняется по числовому Telegram ID, а не по изменяемому
  username.
- Генерация и повторная отправка разрешены только в личном чате.
- Значения пользователя экранируются перед вставкой в HTML.
- WeasyPrint запрещено загружать внешние ресурсы при рендеринге.
- Проверка формата ID препятствует использованию произвольного пути или имени
  файла.
- Ограничение запросов снижает риск случайной перегрузки, но не заменяет
  серверный мониторинг и резервное копирование.
- SQLite рассчитана на локальный запуск одного экземпляра бота. Для нескольких
  экземпляров на разных серверах потребуется общее хранилище и база.

Не помещайте токены, клиентские данные, PDF или SQLite-базу в репозиторий.
Правила `.gitignore` помогают исключить эти файлы, но не удаляют их из Git,
если они уже были закоммичены.

## Запуск тестов

Из корневой папки `VPa06` выполните:

```powershell
python -m unittest discover -s .\tests -v
```

Тесты проверяют обработку пакетов, лимит генерации, запрет групповых команд,
повторную отправку и удаление просроченного PDF с сохранением записи ID.
Вызовы Telegram API в тестах не выполняются.

## Устранение неполадок

### Ошибка `ALLOWED_USER_IDS`

Укажите числовой ID из `/myid`, а не `@username` и не текст вроде
`ваш_ID_из_myid`. Список операторов разделяется запятыми.

### Бот сообщает, что выпуск недоступен

Проверьте `ALLOWED_USER_IDS`, сохраните `.env` и перезапустите бота. Для выпуска
откройте личный чат с ботом, а не группу.

### ID уже использовался

Выберите новый ID. Удаление PDF не удаляет запись из журнала и не освобождает ID.

### PDF не отправился

Если файл был создан, он остаётся в `output/`. Попробуйте `/resend ID`. Команда
работает только пока PDF существует и не истёк срок хранения.

### WeasyPrint не устанавливается или не генерирует PDF

Проверьте, что зависимости устанавливаются в используемое Python-окружение, и
следуйте актуальной инструкции установки WeasyPrint для Windows. Сообщения об
ошибках генерации выводятся в журнал процесса бота.
