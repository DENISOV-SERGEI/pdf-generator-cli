# Telegram-бот для генерации PDF-документов

![Интерфейс Telegram-бота](./screenshot.png)

Учебный проект на Python: Telegram-бот создаёт именные дипломы и подарочные
сертификаты из HTML-шаблонов, сохраняет готовые PDF в `output/` и отправляет
их пользователю. Для рендеринга HTML используется WeasyPrint.

## Возможности

- Генерация дипломов и сертификатов через команды `/diploma` и `/gift`.
- Пакетный выпуск до 10 документов из одного сообщения.
- Разрешение на выпуск только для Telegram ID, заданных в конфигурации.
- Работа с выпуском и повторной отправкой документов только в личном чате.
- Глобальная проверка уникальности ID в SQLite-журнале.
- Ограничение выпуска до 10 документов на оператора за 10 минут.
- Сохранение PDF в `output/` и повторная отправка командой `/resend`.
- Автоматическое удаление PDF по истечении срока хранения при запуске бота
  и перед обработкой команд выпуска или повторной отправки.
- HTML-экранирование пользовательских значений и запрет загрузки внешних
  ресурсов во время рендеринга.

## Требования

- Python 3.10 или новее.
- Токен Telegram-бота, созданного через BotFather.
- Системные компоненты WeasyPrint, если их требует ваша версия Windows или
  Python. При проблемах установки сверьтесь с актуальной инструкцией WeasyPrint.

Зависимости Python перечислены в [requirements.txt](./requirements.txt):
`pyTelegramBotAPI`, `python-dotenv` и `WeasyPrint`. Версии основных библиотек
зафиксированы в проверенном окружении проекта.

## Установка в Windows

Откройте PowerShell в папке проекта `VPa06` и выполните:

```powershell
python -m venv .\venv
.\venv\Scripts\Activate.ps1
python -m pip install -r .\requirements.txt
```

Если PowerShell запрещает запуск скрипта активации, используйте Python
из виртуального окружения напрямую:

```powershell
.\venv\Scripts\python.exe -m pip install -r .\requirements.txt
```

## Настройка

Создайте файл `.env` в папке рядом с `bot_generator.py`. Если в нём уже записан
`BOT_TOKEN`, сохраните его и добавьте другие настройки:

```dotenv
BOT_TOKEN=токен_от_BotFather
ALLOWED_USER_IDS=123456789
PDF_RETENTION_DAYS=30
```

Для новых установок можно скопировать безопасный пример конфигурации:

```powershell
Copy-Item .\.env.example .\.env
```

Затем откройте `.env` и укажите значения. Не помещайте реальный токен в
`.env.example`.

### Переменные окружения

| Переменная | Обязательна | Назначение |
|---|---:|---|
| `BOT_TOKEN` | Да | Секретный токен Telegram-бота. |
| `ALLOWED_USER_IDS` | Для выпуска | Разрешённые числовые Telegram ID. Несколько ID разделяются запятыми, например `123456789,987654321`. Если значение пустое, выпуск недоступен. |
| `PDF_RETENTION_DAYS` | Нет | Срок хранения PDF в днях. По умолчанию — `30`; значение должно быть положительным целым числом. |

Чтобы узнать свой Telegram ID, запустите бот и отправьте ему `/myid`. Команда
показывает числовой ID отправителя. Добавьте это число в `ALLOWED_USER_IDS`,
сохраните `.env` и перезапустите бота. Для первоначальной настройки можно
оставить `ALLOWED_USER_IDS` пустым: бот запустится и ответит на `/myid`, но
генерировать документы до заполнения списка будет нельзя.

**Не публикуйте `.env` и не отправляйте его содержимое посторонним.** Файл
исключён из Git настройкой `.gitignore`. Если токен оказался опубликован,
отзовите его через BotFather и настройте новый.

## Запуск и остановка

Запустите бота из папки `VPa06`:

```powershell
python .\bot_generator.py
```

Чтобы остановить его в этом же терминале, нажмите **Ctrl+C**. После изменения
`.env` бот нужно перезапустить, иначе он продолжит использовать предыдущие
настройки.

## Использование

### Команды

| Команда | Назначение |
|---|---|
| `/start` | Показать приветствие и основные команды. |
| `/myid` | Узнать свой числовой Telegram ID. |
| `/diploma` | Начать выпуск дипломов. |
| `/gift` | Начать выпуск подарочных сертификатов. |
| `/resend ID` | Повторно отправить сохранённый PDF по ID документа. |

Выпуск и повторная отправка разрешены только пользователям из `ALLOWED_USER_IDS`
и только в личном чате с ботом. Команды генерации в группах отклоняются.

### Пакетная генерация

После `/diploma` или `/gift` отправьте одно сообщение, где каждая запись занимает
отдельную строку:

```text
Анна Иванова : Python : diploma-001
Борис Петров : Веб-разработка : diploma-002
Вера Сидорова : Дизайн : diploma-003
```

Формат строки:

```text
Имя : Название курса или услуги : ID документа
```

Бот сформирует отдельный PDF на каждую строку и отправит файлы по очереди.
Если вы передумали, отправьте команду, начинающуюся с `/`, вместо списка —
ожидание ввода будет отменено.

### Правила для данных

- В одном сообщении допускается от 1 до 10 непустых строк.
- Имя обязательно; максимальная длина — 120 символов.
- Название обязательно; максимальная длина — 200 символов.
- ID обязателен, длина от 1 до 64 символов; разрешены буквы, цифры,
  подчёркивание и дефис.
- ID должны быть уникальны в текущем пакете и во всём журнале выпусков.
  Повторно использовать ID нельзя, даже если исходный PDF уже удалён.
- Двоеточие разделяет поля. Не используйте его внутри имени или названия.

Ошибки проверки списка исправьте и отправьте весь пакет повторно: частичная
генерация из некорректного списка не выполняется.

## Лимит выпуска

Один оператор может выпустить не более **10 PDF за скользящее окно в 10 минут**.
Учитывается количество созданных документов, а не количество сообщений:
например, пакет из 5 документов использует 5 единиц лимита. Проверка выполняется
атомарно вместе с записью ID в базу. Повторная отправка уже созданного PDF
командой `/resend` новый документ не выпускает и в этот лимит не входит.

## Файлы и хранение

| Путь | Содержимое |
|---|---|
| `bot_generator.py` | Обработчики Telegram, проверки и логика выпуска. |
| `templates/diploma_template.html` | HTML-шаблон диплома. |
| `templates/gift_certificate.html` | HTML-шаблон подарочного сертификата. |
| `output/` | Сгенерированные PDF и база данных выпусков. |
| `output/issued_documents.sqlite3` | Журнал выданных ID, времени выпуска, имени PDF и Telegram ID оператора. |
| `tests/test_bot_generator.py` | Автоматические тесты ключевого поведения. |

PDF сохраняются под именами вида:

```text
document_<ID>_<chat_id>_<message_id>.pdf
```

Файлы старше `PDF_RETENTION_DAYS` удаляются при старте бота и перед командами
выпуска или повторной отправки. **Записи об ID в SQLite не удаляются**: журнал
предотвращает повторную выдачу номера после удаления PDF. Если срок хранения
истёк, `/resend ID` не сможет отправить файл — документ нужно будет найти в
резервной копии, если она есть.

Папка `output/` исключена из Git, поскольку содержит документы с персональными
данными и локальную базу. Регулярно делайте защищённую резервную копию
`output/issued_documents.sqlite3`, если история выпусков важна. Храните резервные
копии PDF отдельно и с контролем доступа.

## Безопасность и ограничения

- Токен читается через `python-dotenv` из `.env`; отсутствие `BOT_TOKEN`
  останавливает запуск с ошибкой конфигурации.
- Список разрешённых операторов проверяется при запуске генерации и повторной
  отправки; для выпуска также требуется личный чат.
- `ALLOWED_USER_IDS` должен состоять из числовых Telegram ID, разделённых
  запятыми. Username не используется для авторизации.
- Значения, подставляемые в HTML, экранируются. WeasyPrint настроен так, чтобы
  не загружать URL или другие внешние ресурсы из HTML.
- ID ограничен безопасным набором символов и используется в имени файла.
- Не добавляйте секреты или пользовательские PDF в репозиторий.
- SQLite — локальная база для одного экземпляра бота. Для запуска нескольких
  копий на разных серверах понадобится общее надёжное хранилище и база данных.

## Тесты

Из папки `VPa06` выполните:

```powershell
python -m unittest discover -s .\tests -v
```

Тесты проверяют разбор пакета, ограничение частоты выпуска, отказ при превышении
лимита, защиту от команд в группе, повторную отправку и удаление просроченного
PDF с сохранением записи ID в журнале. Вызовы Telegram API в тестах не
выполняются.

## Типичные проблемы

### Ошибка про `ALLOWED_USER_IDS`

Проверьте, что значение — числовой ID, а не текст `ваш_ID_из_myid` и не
`@username`. Узнать число можно командой `/myid`. Если ID несколько, разделите
их запятыми без дополнительных символов.

### Бот отвечает, что выпуск недоступен

Убедитесь, что ваш ID присутствует в `ALLOWED_USER_IDS`, `.env` сохранён и бот
перезапущен. Для выпуска используйте личный чат, а не группу.

### ID уже использовался

Каждый ID можно выпустить только один раз. Удаление PDF по сроку хранения не
освобождает ID. Выберите новый уникальный ID.

### PDF не удалось отправить

Если файл уже создан, он остаётся в `output/`. В личном чате с разрешённого
аккаунта попробуйте `/resend ID`. Команда работает, пока PDF существует и не
истёк срок хранения.

### WeasyPrint не устанавливается или не создаёт PDF

Проверьте установку зависимостей в активном Python-окружении и следуйте
актуальным инструкциям установки WeasyPrint для Windows. Сообщения об ошибках
генерации записываются в журнал процесса бота.
