# Генератор PDF-чеков и счетов

Небольшой CLI-проект на Python для создания PDF-документов по данным заказов. Программа помогает выбрать файл с заказами и оформление документа, находит нужную запись по `invoice_id`, подставляет её значения в HTML-шаблон и создаёт PDF.

Генерация выполняется библиотекой **WeasyPrint**. В шаблонах используется UTF-8 и шрифт с поддержкой кириллицы, поэтому текст на русском языке может отображаться в PDF корректно.

## Возможности

- Поиск файлов `.csv` и `.json` в папке `data`.
- Поиск HTML-шаблонов в папке `templates`.
- Интерактивный выбор файла данных, оформления и заказа.
- Выбор заказа как по номеру в меню, так и по `invoice_id`.
- Подстановка значений заказа в плейсхолдеры вида `{{ invoice_id }}`.
- Экранирование значений для безопасной вставки в HTML.
- Сохранение PDF с именем `invoice_[ID].pdf` в папку `output`.
- Автоматическое открытие готового документа в приложении по умолчанию.
- Проверка пустых списков, неверного выбора, отсутствующих или повторяющихся ID и полей, которых не хватает шаблону.

## Структура проекта

```text
VPa06/
├── data/
│   └── invoices.csv          # Пример исходных заказов
├── templates/
│   ├── invoice_template.html # Базовый шаблон
│   ├── invoice_modern.html   # Современное оформление
│   ├── invoice_dark.html     # Тёмное оформление
│   └── invoice_strict.html   # Строгое оформление
├── output/                   # Сюда сохраняются созданные PDF
├── pdf_generator.py          # CLI-генератор
└── README.md                 # Описание проекта
```

Папки `data`, `templates` и `output` определяются относительно расположения `pdf_generator.py`, а не текущей папки терминала. Если `output` отсутствует, программа создаст её при генерации документа.

## Требования

- Python 3.10 или новее.
- Библиотека WeasyPrint.
- Установленный в системе PDF-просмотрщик для автоматического открытия результата.

Установите библиотеку в используемое Python-окружение:

```powershell
python -m pip install weasyprint
```

В некоторых системах WeasyPrint также требует системные библиотеки. Если установка или генерация завершается ошибкой, следуйте актуальным инструкциям установки для вашей операционной системы на сайте WeasyPrint.

## Запуск в Windows

Откройте PowerShell в корне репозитория и выполните:

```powershell
cd .\VPa06
python -m pip install weasyprint
python .\pdf_generator.py
```

При запуске программа предложит:

1. выбрать CSV- или JSON-файл из `data`;
2. выбрать HTML-файл из `templates`;
3. выбрать заказ по его номеру в списке или по `invoice_id`.

После успешной генерации появится сообщение с путём к PDF, и Windows откроет его в приложении, назначенном для PDF-файлов.

На macOS для открытия используется команда `open`, а на Linux — `xdg-open`.

## Формат данных

### CSV

CSV должен содержать заголовки в первой строке. Обязательное поле — `invoice_id`. Все поля, используемые выбранным HTML-шаблоном, должны быть в той же строке заказа.

Минимальный набор полей для имеющихся шаблонов:

| Поле | Назначение | Пример |
|---|---|---|
| `invoice_id` | Уникальный идентификатор заказа | `1001` |
| `customer_name` | Имя клиента | `Иван Иванов` |
| `date` | Дата заказа или документа | `2026-10-28` |
| `product` | Название товара или услуги | `Беспроводные наушники` |
| `qty` | Количество | `2` |
| `price` | Цена | `12000` |

Файл может быть сохранён в UTF-8; для CSV с BOM также предусмотрено чтение.

### JSON

JSON может содержать непосредственно список заказов:

```json
[
  {
    "invoice_id": "1001",
    "customer_name": "Иван Иванов",
    "date": "2026-10-28",
    "product": "Беспроводные наушники",
    "qty": 2,
    "price": 12000
  }
]
```

Также поддерживаются список в объекте под ключом `orders`, `invoices` или `data`, либо один объект заказа:

```json
{
  "orders": [
    {
      "invoice_id": "1001",
      "customer_name": "Иван Иванов",
      "date": "2026-10-28",
      "product": "Беспроводные наушники",
      "qty": 2,
      "price": 12000
    }
  ]
}
```

Для каждого заказа `invoice_id` должен присутствовать и быть уникальным в выбранном файле.

## HTML-шаблоны

Шаблон — это HTML-файл с обычной разметкой и CSS. Чтобы вставить значение из заказа, используйте двойные фигурные скобки и точное имя поля:

```html
<h1>Счёт № {{ invoice_id }}</h1>
<p>Клиент: {{ customer_name }}</p>
<p>Дата: {{ date }}</p>
<p>Товар: {{ product }}</p>
<p>Количество: {{ qty }}</p>
<p>Цена: {{ price }} руб.</p>
```

Имя плейсхолдера должно совпадать с ключом в CSV-заголовке или JSON-объекте. Если для плейсхолдера не найдено поле, генератор сообщит об ошибке. Значения вставляются как текст с HTML-экранированием; оформление документа задаётся в самом шаблоне.

Чтобы добавить оформление, поместите новый `.html`-файл в `templates`. Для отображения кириллицы используйте UTF-8 и шрифт с поддержкой кириллических символов, например DejaVu Sans.

## Результат

PDF сохраняется в `output` под именем:

```text
invoice_[invoice_id].pdf
```

Например, для заказа с ID `1001` путь к файлу будет таким:

```text
output/invoice_1001.pdf
```

## Типичные ошибки

- **Не найдены файлы данных или шаблоны** — добавьте CSV/JSON в `data` или HTML-файл в `templates`.
- **Неверный пункт меню** — введите номер из показанного списка.
- **Отсутствует `invoice_id` или поле шаблона** — проверьте заголовки данных и имена плейсхолдеров.
- **Повторяются ID** — задайте каждому заказу уникальный `invoice_id`.
- **WeasyPrint не установлен** — установите его командой `python -m pip install weasyprint` в используемом окружении.
- **PDF не открылся** — проверьте, что в системе установлен PDF-просмотрщик и приложение для PDF назначено по умолчанию.
